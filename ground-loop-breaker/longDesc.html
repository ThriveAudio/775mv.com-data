Safely feed several loads from the same EMI filter

Connecting multiple audio components to a single EMI filter will almost inevitably introduce ground loops, but with our Ground Loop Breaking circuit, you can do so with confidence. All Thrive Audio EMI filter products feature this technology. You will only need this Ground Loop Breaker for every additional load connected to the same filter. The tuneable shunt values allow you to optimize the filtering for each connected device, ensuring that they all receive the cleanest power possible without introducing noise or interference.

The Joy of Tuning

The Ground Loop Breaker lets you fine-tune filtering for each connected device, optimizing performance regardless of your specific components. Whether using a sensitive phono stage or high-powered amplifier, you can adjust settings for optimal common-mode noise suppression.

The tuning adapts the filter's response to each device's internal filtering and earth coupling characteristics. The four-channel DIP switch lets you independently select ideal shunt values for each application.
